Автоматизация E2E-тестирования API

Тесты для API без рутины

Загрузите Swagger — Tapir соберёт базовые сценарии. Правьте их в конструкторе, храните в git и запускайте через CLI, Docker или локальный интерфейс.

  • Open source ядро
  • Без обязательной регистрации
  • Язык интерфейса: EN / RU
tapir.json 
{
  "name": "Petstore E2E",
  "scenarios": [{
    "id": "pet-lifecycle",
    "steps": [
      { "operation": { "operationId": "addPet" },
        "expect": { "status": 200 } },
      { "operation": { "operationId": "getPetById" },
        "expect": { "status": 404 } }
    ]
  }]
}
$ tapir run tapir.json --env stage

Всё, чтобы тесты API
не превращались в хаос

Писать E2E-тесты долго и монотонно, а при каждом изменении ручки их приходится искать и править вручную. Tapir берёт это на себя.

Генерация из Swagger

Загрузите Swagger 2.0 — получите smoke-сценарий на каждую ручку, CRUD-цепочки и простые негативные кейсы (400, 404, 401).

Сценарии живут в git

Один читаемый JSON-файл рядом с кодом. Код-ревью, диффы и ручная правка — как с любым другим файлом проекта.

Актуальность при изменении API

Шаги ссылаются на ручки по operationId. Изменился Swagger — видно, что именно затронуто, и можно выбрать: обновить или пропустить.

Интерактивный конструктор

Редактируйте сгенерированные сценарии и собирайте свои: логин-фикстуры, несколько ролей, передача данных между шагами.

Расхождения со спецификацией

В отчёте — ожидаемый и реальный ответы, а отдельным разделом — всё, что не совпало со схемой Swagger.

Локальный UI и CI

tapir ui в Docker видит приватные API и сети docker-compose. CLI возвращает код выхода и JSON-отчёт — подходит для CI.

Как это работает

От документации до отчёта — четыре шага.

  1. 1

    Загрузите Swagger

    Спецификация в JSON или YAML. Tapir разберёт ручки, схемы и входные данные.

  2. 2

    Получите сценарии

    Базовые сценарии строятся автоматически — их можно сразу запускать или доработать.

  3. 3

    Отредактируйте и сохраните

    Правьте в конструкторе или прямо в JSON. Файл кладётся в git вместе с кодом.

  4. 4

    Запустите и изучите отчёт

    CLI, Docker или локальный интерфейс. В отчёте — запросы, ответы и pass/fail.

Ядро — open source

Формат сценариев, CLI, Docker-образ и локальный интерфейс открыты. Облако Tapir добавляет хранение и дополнительные возможности.
